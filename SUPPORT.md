# Support

Life Ledger is maintained as an open-source, self-hosted project rather than a hosted support service.

## Ask a question

Use [GitHub Discussions Q&A](https://github.com/zubin-li/life-ledger-deep-review/discussions/categories/q-a) for setup questions, deployment guidance, browser behavior, and product use.

Before posting, remove all journal text, calendar details, email addresses, access tokens, account identifiers, and personal photos. A fictional example is usually enough to explain the problem.

## Report a reproducible bug

Use the [bug report form](https://github.com/zubin-li/life-ledger-deep-review/issues/new?template=bug_report.yml) when you can describe exact steps, expected behavior, and the affected browser or device.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public Issue or Discussion.
