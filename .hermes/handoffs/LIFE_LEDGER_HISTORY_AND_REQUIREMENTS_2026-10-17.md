## 二、累计需求（按用户目标归纳）

1. **产品本质**：个人深度复盘系统——每日少量记录 → 每周回顾 → 每月理解；数据属于用户自己。
2. **三种形态并行**：部署网页版（电脑+手机 PWA，全功能）、GitHub Pages 本地版（demo + 导入导出，功能做减法）、Mac 应用（本地模式开箱即用 + 联网模式）。手机只用网页。
3. **联网 = 连自己的部署**，不是作者运营的平台。朋友按 GitHub 自部署（Cloudflare / 国内 CloudBase）。
4. **网页和应用数据相通、结构相似、实现分开**；应用要更原生、更顺手，网页不能比原版差。
5. **今日页卡片化**：可添加/删除/移动；新功能=新卡片；尺寸只给有意义的卡；只在编辑模式下移动和设置。其他页面保持现状。
6. **质量底线**：苹果风格、圆润、悬浮岛/泡泡感、动效、hover 反馈、深浅色、三语地道、去冗余、改一处不能坏别处、手机端排版正常。
7. **保留全部既有功能**（见上表 6/28–9/26）。
8. **工作方式**：先评估可行性/难度/token 再做；本地预览确认后再部署；每版可回退；自己先检查渲染再交付；发布即全平台同步 + README 新功能说明 + 详细 commit。
