# Today：组件交互、天气与动效修订提案

状态：用户已批准分阶段实施；首个检查点实现天气曲线/欢迎卡天气与独立组件库，待用户视觉确认。已本地复用 MIT 开源 uPlot 与 Motion mini，未安装新全局 skill。心情/月度热力图视觉修订待后续。现有未提交代码与原型保持不动。禁止委派、发布或替换本机应用。

## 已从现有代码确认的问题

- `public/today-extras.js` 的天气由 range 滑块和小时按钮组成，没有温度曲线；当前天气与探索未来小时也未形成清楚的信息层级。
- `public/layout-engine.js` 在编辑时展示所有 hidden 组件，使未添加组件仍以占位卡参与 CSS 排版；组件目录和工作台没有真正分离。
- 当前热力图未来日期采用低透明度，缺日期数字与清楚的格子边界。
- 心情沿用一排紧凑分段按钮，但独立卡片留下较多空白，控件层级不适合当前尺寸。
- 用户报告的专注/近期完成率重叠必须在当前真实布局复现并检查；不能仅凭旧尺寸矩阵测试推断其不存在。

## 修改标准

1. 天气分两层：欢迎卡只显示当前图标、温度、地点；可选天气卡显示温度曲线，横轴明确标出早上/中午/晚上/次日时间，纵轴摄氏温度。鼠标探索曲线时蓝点/指示线跟手，读数显示该小时温度及降水，键盘也可操作；探索不改变顶部的当前天气。今日最高/最低必须来自同一个当地自然日，不能混用滚动 24 小时区间。
2. 心情保留已有图标及数据语义，改成更舒展的独立选项和明确选择反馈；理由按需展开，不新增记录模型或强制多选项。
3. 月度热力图显示星期、完整日期数字、可辨认的未来日期边框与八级完成颜色。按内容选择合理默认尺寸，不为了维持小点而留下大块无意义空白；S/M/L 的信息降级与内容边界需实际截图确认。
4. 组件目录放在独立添加面板中，提供所有现有组件的预览与添加操作；未添加项不出现在工作台或编辑栅格。展示验收可临时使用虚构数据添加全部组件，不能因此改变用户原来的布局。
5. 正常模式固定；编辑模式移动/配置。统一标题、间距、尺寸与设置入口，修复用户所述重叠。Mac 可自由定位；未来网页版复用同一组件内容、设置和设计令牌，采用自动排版及勾选显示，不在本轮改线上网站。
6. 动效用于打卡确认、颜色反馈、添加/移除、面板展开和拖动释放的连续性。直接拖动不得有跟手延迟；避免同一 transform 被现有 FLIP 和新库同时控制；快速反复操作可打断，深浅色与 reduced/off 保持最终状态一致。

## 已核对的开源候选（不等于已接入）

- [uPlot](https://github.com/leeoniya/uPlot)：MIT，原生 JavaScript 时间序列图表；优先验证其坐标轴、光标和小卡片尺寸。不是整套天气应用，也不会自动解决字体与坐标标签布局。
- [Motion](https://github.com/motiondivision/motion)：MIT，支持原生 JavaScript；按需使用免费部分。官方 README 也提供免费 agent skill 的入口；不默认安装 MCP 或购买 Motion+。
- [AutoAnimate](https://github.com/formkit/auto-animate)：MIT，可用于普通 DOM 增删重排；是备选，不能与 Motion/现有布局动画无差别叠加。
- [Motion Primitives](https://github.com/ibelick/motion-primitives)：MIT，动画组件参考。整套项目技术栈与当前应用不同，不为复制示例而重写应用。
- [OSS Weather](https://github.com/ossappscollective/oss-weather)：MIT，参考天气应用的信息组织；NativeScript 代码不直接移植为本项目组件。
- [Vercel web-design-guidelines](https://skills.sh/vercel-labs/agent-skills/web-design-guidelines)：官方来源、目录约 73.8 万安装；适合作为交互/可访问性检查，不作为美感已经通过的证明。现有 frontend-design 与 ui-animation 继续按需使用，不批量安装重复 skill。

## 建议实施检查点

先确认天气曲线＋顶部摘要的真实视觉，以及组件目录/工作台分离的交互；随后按相同设计契约修订心情、月历和其余现有卡片。每个检查点交付真实浅/深色截图和操作录屏，再由用户确认，不仅检查测试是否绿色。

必须验证：无布局重叠、没有未添加占位卡；各尺寸不溢出；曲线悬停/键盘读数正确且顶部当前天气不跳变；城市时区和最高最低一致；心情保持原数据；组件添加移除和布局可持久化；动画能中断且低动态可用。新增第三方源码需保留许可证，固定版本并验证离线资源；不得仅用 CDN 让本地 App 的图表依赖网络加载。
