# Timeline / Insights checkpoint

2026-10-15. User visual confirmation pending. No commit, push, package, deploy or installation.

## What changed

- One chronological vertical feed for daily / weekly / monthly writing, with optional month selection and 24-entry pagination. A cross-month week appears for either intersecting month. Existing weeklyOutputs, weeklyReviews and reviews are read directly; no migration or duplicate records.
- Daily media remains on its actual date. Weekly media loads only when explicitly expanded. Monthly reviews do not duplicate daily photos. The existing daily drawer, photo library and calendar remain available.
- Insights distinguishes recorded completion / planned opportunities, recorded-day coverage, and saved focus time. The time window ends on the selected date, capped at today; it is explicitly displayed, not implied to be a full calendar month.
- Per-habit percentages use that date's effective version and the existing countsTowardDaily flag. Only currently active habits are compared. Missing log entries remain in the planned denominator; they are not proof that a habit was missed. The trend has gaps for missing entries, and the heatmap labels missing/no-plan cells separately from recorded zero.
- Changes compare equal-length previous/current windows only after each has at least 7 recorded days, and each compared habit has at least 7 opportunities in each window. These are descriptive observations, not significance tests, recommendations generated by AI, or causal conclusions. Changed habit configuration or logging frequency can affect comparisons.
- Weekday percentages are weighted completed/planned slots rather than an unweighted mean of daily percentages. Current weekly/monthly non-daily-scored targets are displayed separately, as of the window's end, using the effective frequency. They are not a historical period-success score. No new streak algorithm was introduced.

## Research and reuse

- [Loop Habit Tracker](https://github.com/iSoron/uhabits): habit strength should not be reduced to a single unbroken streak. GPL-3.0 project; conceptual reference only. Its scoring formula and source were not copied or claimed implemented.
- [OpenHabitTracker statistics](https://openhabittracker.net/habit-tracker-statistics.html): separate target windows, per-habit history, weekday frequency and progressive disclosure. [Repository license](https://github.com/Jinjinov/OpenHabitTracker/blob/master/LICENSE) is GPL-3.0; no source copied.
- Implementation reuses this project's analytics date/rate helpers, effective habit versions, original icons, photo manager and review storage. No new dependency, downloaded UI kit, remote model call or external account access was added.

## Known boundaries

- All-month daily browsing queries photo metadata across history; rendered entries are paginated but metadata is not server-paginated. Large libraries may warrant range-based metadata pagination later.
- Reviews remain plain text with safely escaped simple heading rendering, not a new rich-text editor. Legacy weekly note/review stores remain distinct; identical text is not repeated within one entry.
- Existing photo format/count/sync limits and connected-calendar restrictions are unchanged.
- No new automatic habit suggestions, mood correlation, notifications, native-calendar connection or remote AI analytics were added.
