# Life Ledger 2.1.0 — 自 v2.0.10 以来改了什么

面向主人的变更说明（无代码）。版本：**网页 2.1.0**、**Mac 3.1.0**。基准标签：**v2.0.10**。

---

## 新功能

1. **内置记账（`state.ledger`）**  
   - **哪里：** 侧栏 **「记账」**（€ 图标）；Mac **显示 → 记账（⌘5）**；任意页面按 **M** 打开记账并聚焦快速录入。  
   - **看见什么：** 账户、分类（图标/颜色）、交易、预算、固定收支模板；金额用整数「分」存储；与本地保存、云同步 CAS、备份 v3、撤销删除一并生效。旧数据没有 `ledger` 字段时行为与 2.0.10 相同。

2. **今日 ·「今日支出」卡片**  
   - **哪里：** **今日** 页卡片网格（可像其它卡片一样显示/隐藏、改大小、排序）。  
   - **看见什么：** 当日支出合计（数字会滚动更新）、与昨日对比一行、本月侧面提示、近 7 天迷你支出条；无记录时有引导文案。  
   - **怎么点：** 点 **当日金额** 或卡片上的记一笔入口 → 弹出 **快速记账** 面板（半透明遮罩 + 底部卡片）。

3. **快速记账面板（今日）**  
   - **哪里：** 从 **今日支出** 卡片打开。  
   - **看见什么：** 标题、**今日合计**、一行输入（如 `12,50 咖啡`）、**分类小 chip**（可点切换分类）、**保存**、最近 2～3 笔、**查看完整统计** 文字按钮。  
   - **怎么点：** 输入后 **保存** 或键盘确认；点 chip 循环切换分类；**查看完整统计** 进入记账页并定位到所选规划日。

4. **复盘 · 本月支出（Money）**  
   - **哪里：** **复盘** 页 **本月支出** 区域（含散点图、预算超标列表等）。  
   - **看见什么：** 支出/收入/结余、较上月同期对比、心情×支出 / 习惯×支出 / 专注×支出散点图（可键盘聚焦看读数）、跳转 chip、折叠的「详细指标」。  
   - **怎么点：** 点 **支出/收入/结余** 或 **打开记账** → 带着当前复盘月份进入 **记账**；散点图上的 chip 滚动到对应图表。

5. **本周 · 数据洞察 · 本周支出**  
   - **哪里：** **本周** 页洞察区第五格。  
   - **看见什么：** 本周（周一至今天）支出合计与 **较上周同期** 提示。  
   - **怎么点：** 点该格 → 进入 **记账** 对应月份。

6. **演示工作区**  
   - **哪里：** 首次本地/云演示加载。  
   - **看见什么：** 约 90 天欧元示例交易、预算、固定项，并与心情/习惯/专注示例对齐，便于散点与洞察文案。

7. **德语 CSV 导入/导出**  
   - **哪里：** **记账** 页右上角 **「⋯」** 菜单。  
   - **看见什么：** 分号分隔、小数逗号、`DD.MM.YYYY` 等格式；导入前有预览表。

8. **PWA 离线**  
   - **哪里：** 已安装 PWA 离线时。  
   - **看见什么：** 记账相关脚本可从缓存加载（`ledger-core.js` / `ledger-ui.js` 纳入 Service Worker 管理列表）。

## 记账

1. **记账页 = 统计 + 完整列表（主人反馈后的结构）**  
   - **哪里：** **记账** 页。  
   - **看见什么：** 顶栏 **单日切换（‹ 日期 ›）**、快速录入一行、**周 / 月** 切换、收入/支出/结余、与上周/上月同期 **一行对比**、分类 **圆环图**（主视图仅圆环，无 treemap 切换）、月视图下 **每日细条**、**每月订阅** 列表、按日分组的 **精简交易列表**；搜索、CSV、预算、固定收支等在 **「⋯」** 里。  
   - **怎么点：** **周/月** 按钮切换统计范围；点某日分组标题展开/折叠其它日期；交易行上 **分类 chip** 打开编辑；**⋯** 打开更多功能。

2. **自动分类 + 学会你的修正**  
   - **哪里：** 快速录入（今日面板与记账页）、保存后列表里的 chip。  
   - **看见什么：** 根据备注关键词（中/英/德，如 咖啡/Kaffee、Miete/房租、Rewe/Lidl…）推断分类；改过一次分类后会记住该备注。未知 → **其他**。  
   - **怎么点：** 今日面板点 **分类 chip** 循环切换；记账列表点 chip 编辑。

3. **每月订阅**  
   - **哪里：** **记账** 页 **「每月订阅」** 卡片。  
   - **看见什么：** 名称、金额、每月几号、分类；**月** 统计视图下显示 **每月订阅合计**（仅支出、默认货币）。  
   - **怎么点：** 打开记账页时到期订阅 **自动记一笔**（每月一次、可撤销）；在 **⋯** 里管理固定收支。

4. **交易列表变瘦**  
   - **哪里：** **记账** 页 **「交易」** 区。  
   - **看见什么：** 一行一笔（分类首字母图标 · 备注 · 金额）；按日分组，**今天** 展开，更早日期默认折叠为一行日合计；编辑/删除在 popover 或行内按钮，不是大卡片。

5. **侧栏顺序**  
   - **哪里：** 左侧栏 / 手机底栏 / Mac 菜单。  
   - **顺序：** **今日 → 本周 → 长期 → 时间轴 → 记账 → 复盘 → 习惯设置**（记账在 **时间轴下面、复盘上面**）。

6. **页面标题**  
   - **哪里：** **记账** 页。  
   - **看见什么：** 仅 **一处**「记账」标题（顶栏应用标题），不再有重复的区块大标题。

7. **移除手机大键盘**（最终轮）  
   - **哪里：** **记账** 页。  
   - **看见什么：** 不再出现底部 13 键 **金额键盘**；手机用系统键盘输入，页面底部留白恢复正常。

8. **对比文案修复**（最终轮 · 审查意见）  
   - **哪里：** **记账** 页 **周/月** 统计下的 **较上周/上月同期** 一行。  
   - **看见什么：** 不再出现 **`+null%`**；百分比带 **`%`**；基线很小时显示 **金额差**（与今日卡片、复盘逻辑一致）。

9. **备份里的「今日支出」卡片**（最终轮 · 审查意见）  
   - **哪里：** 设置里 **导出/导入** 完整 v3 备份。  
   - **看见什么：** **今日支出** 卡片的顺序、大小（S/M）、隐藏状态会随备份保留，不再被静默丢掉。

## 动效与交互

1. **侧栏换页 · View Transitions**  
   - **哪里：** 点侧栏 **今日/本周/…/习惯设置**。  
   - **看见什么：** 支持时前后页 **方向淡入**；系统 **减少动效** 时自动改为普通切换。

2. **统一按压反馈（`pressBump`）**  
   - **哪里：** 侧栏、chip、统计按钮、今日记一笔、记账分类 chip 等。  
   - **看见什么：** 轻按 **缩放/透明度** 反馈（仅 transform/opacity）。

3. **数字滚动（roll-up）**  
   - **哪里：** 今日支出合计/对比、记账统计区收入/支出/结余、本周洞察部分 KPI、快速记账面板 **今日合计** 等。  
   - **看见什么：** 数字变化时 **滚动过渡**，减少动效时直接跳变。

4. **记账 · 日分组 FLIP**  
   - **哪里：** **记账** 交易列表展开 **其它日期**。  
   - **看见什么：** 展开/折叠时列表 **平滑重排**，不是生硬跳变。

5. **新交易进入列表**  
   - **哪里：** 刚保存的一笔。  
   - **看见什么：** 行 **淡入/滑入** 高亮。

6. **圆环与页面进入**  
   - **哪里：** 进入 **记账**、统计区渲染。  
   - **看见什么：** 分类圆环 **描边动画**；面板 **错峰进入**（减少动效时关闭）。

7. **今日快速记账面板**  
   - **哪里：** 打开/关闭 **快速记账**。  
   - **看见什么：** 面板 ** spring 感** 开合；保存成功 **短脉冲**。

8. **复盘 · Money 散点**  
   - **哪里：** **复盘** 页散点区。  
   - **看见什么：** 先出摘要与 jump chip，散点 **分帧加载**（skeleton + `aria-busy`），洞察文案 **空闲时再填**，避免卡住首帧。

9. **Mac**  
   - **哪里：** Mac 壳菜单。  
   - **看见什么：** **View → 记账 ⌘5**；与侧栏顺序一致。

研究记录见 `.overnight/MOTION-RESEARCH.md`（未改视觉风格，只加强交互顺滑）。

## 细节打磨

- **今日 · 编辑卡片：** 首次提示「今日页可按你的习惯排列…」；**完成** 编辑后有成功脉冲。  
- **浮层实色：** 引导卡、快速记账面板、设置/组件库 **dialog**、记账 popover 等使用 **`--ll-surface-float`**，不再用半透明 `--card` 玻璃（习惯卡片不会透出来）。  
- **今日 · 编辑工具栏 / tc-bar：** 编辑模式下工具条实色底。  
- **记账与本周/复盘：** 同一套 **panel** 圆角、间距、字号。  
- **空态 CTA：** 本周目标、复盘习惯分、时间轴日历空月等统一 **主按钮 + hairline 图**。  
- **记账 · 筛选：** 列表可显示 **筛选小计**；**Esc** 可清搜索/日/分类筛选（无 popover 时）。  
- **深链：** 今日/复盘/本周点支出相关入口 → 记账 **带日或带月**；复盘散点 checklist pill → **今日/习惯/记账**。  
- **三语文案：** 中/英/德界面字符串与 README/CHANGELOG 对齐。  
- **触控目标：** 主要按钮 ≥44px（手机）、桌面 ≥32px 为主流控件。  
- **最终轮：** 快速记账 **最近几笔** 显示分类 **首字母** 图标（不再显示 `coffee` 等内部 key）。

## 已知限制

1. **`public/v210.css` 体积**  
   当前约 **5968 行**（已从 ~6500 删 dead 规则、去掉 treemap/键盘等样式），仍 **未达到** 规格「少于原 6500 行一半（~3250）」；大规模瘦身需 **2.2 拆文件/归档**（见 `.overnight/CSS-LAYERS.md`），避免误删测试依赖的 Batch 注释块。

2. **Headless 天气**  
   无 Open-Meteo 网络时 **今日天气** 卡片为空，与 v2.0.10 一致；写入 offline cache 后可显示缓存温度。

3. **与 v2.0.10 像素 diff**  
   `.overnight/diff-v2010.json`：大面积差异来自 **2.1 新功能面**（今日支出卡、记账 nav、动效），非布局破图。

4. **复盘首帧性能**  
   导航性能追踪在 **复盘** 切换时仍可能有 **~50–65 ms** long task（首帧散点 SVG）；已 idle/分帧，未完全消除。

5. **`npm run test:browser`**  
   76 项中 **fakecloud** 套件依赖本机 **5299** 端口 stub，偶发环境占用会导致失败；**`npm test`（434）** 与 **`npm run desktop:check`（23）** 为发布门闸。

6. **`.overnight/` 维护脚本**  
   除 **`capture.mjs`** / **`capture-mac.mjs`** 外仍保留 prune/compare/perf 等 **一次性** 脚本（审查建议只留 capture；未删以免丢失瘦身记录）。
